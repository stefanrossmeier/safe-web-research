# Code of Conduct

## Our standard

Be respectful, constructive, and specific. Technical disagreement is welcome; harassment,
personal attacks, discrimination, threats, doxxing, and deliberate disruption are not.

Contributors should assume good intent, focus criticism on ideas and code, disclose relevant
security concerns responsibly, and avoid posting another person's private information.

## Scope

This code of conduct applies to repository issues, pull requests, discussions, reviews, and other
project spaces where someone is participating on behalf of this project.

## Enforcement

Maintainers may edit, hide, reject, or remove contributions that violate these expectations and may
restrict participation when necessary. For sensitive conduct concerns, contact the maintainer
privately through the contact method listed on the maintainer's GitHub profile rather than opening a
public issue.
