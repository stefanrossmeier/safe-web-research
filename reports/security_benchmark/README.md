# Security Benchmark Reports

Generated by:

```bash
uv run python -m benchmarks.security
```

The deterministic benchmark makes no live model/network calls. It records the source Git revision, aggregate containment metrics, and every per-case outcome.

Files:

- timestamped Markdown/JSON: immutable evidence for a specific run;
- `latest.md` / `latest.json`: convenience copy of the newest recorded run.

Methodology: [`../../benchmarks/security/README.md`](../../benchmarks/security/README.md).

A clean result is evidence for the committed corpus and benchmark semantics, not proof against all future attacks.
